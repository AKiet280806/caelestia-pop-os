`wallpaper.svg` is an original abstract geometric illustration created for this
repository and dedicated to the public domain under CC0-1.0. `wallpaper.png` is
its 2560×1600 raster rendering for Qt image support. No private desktop image or
third-party wallpaper is included. The source SVG can be rendered with librsvg
or a compatible SVG renderer.
